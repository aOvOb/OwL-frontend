# 관리 화면 Changelog

관리 화면(admin.<도메인>)의 변경 이력입니다. 음악 앱(루트의 CHANGELOG.md)과 버전을 따로 매깁니다.
버전은 `admin/version.json`에 있습니다.

## 0.1.0 (2026-11-26)
- 음악 앱에서 분리: 따로 빌드하고 따로 배포함. 관리 화면만 바꾸면 음악 앱은 다시 배포되지 않음
- 서버 상태: CPU 부하, 메모리, 디스크, CPU와 메모리 그래프(1시간, 24시간, 7일), 이번 달 요금, 매일 백업, 집 인터넷 통로, 서비스별 상태, 버전
- 사용자 활동: 계정별 사용 중 여부, 마지막 접속, 지금 듣는 곡, 재생, 다운로드 수, 날짜별 재생, 많이 들은 가수, 최근 기록
- 곡 관리: 서버의 곡 찾기, 제목, 가수, 앨범 고치기, 지우기
- 다운로드 대기열
